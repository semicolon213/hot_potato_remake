개인정보처리방침

시행일: 2026년 11월 1일 · 서비스명: HP ERP (뜨거운 감자)

HP ERP(뜨거운 감자, 이하 "서비스")는 학과 구성원(학생, 교수, 조교, 학생회 등)이 공지, 일정, 문서, 회계, 학생·교직원 관리 같은 학과 행정 업무를 처리하도록 돕는 웹 서비스입니다. 서비스는 Google 계정으로 로그인하며, 아래에 적은 범위에서만 Google 사용자 데이터에 접근합니다. 이 방침은 서비스가 Google 사용자 데이터를 어떻게 접근, 사용, 저장, 공유, 삭제하는지 설명합니다.

1. 서비스가 접근하는 Google 사용자 데이터

로그인할 때 Google 동의 화면에서 아래 권한을 요청합니다. 각 권한은 표에 적은 기능에만 사용합니다.

데이터 및 권한 사용하는 기능
기본 프로필(이메일 주소, 이름)
email, profile		 본인 확인, 회원가입과 승인, 화면에 사용자 이름 표시
Google 스프레드시트
spreadsheets		 서비스가 데이터 저장소로 쓰는 스프레드시트(공지, 회계 장부, 학생·교직원 명단, 문서 목록, 개인 설정 등)를 읽고 기록합니다.
Google 드라이브
drive		 사용자 드라이브에 서비스 전용 폴더(hot_potato_remake와 하위 폴더)와 개인 설정 파일을 만들고, 그 안의 문서와 서식을 만들고 복사하고 수정하고 삭제합니다. 학과 공유 폴더의 문서와 서식 목록을 조회하고, 사용자가 요청할 때 문서를 다른 구성원이나 학과 Google 그룹과 공유합니다. 회계 장부를 Excel 파일로 내보낼 때 임시 사본을 만들어 내려받은 뒤 삭제합니다.
Google 캘린더
calendar.events, calendar.readonly		 사용자의 기본 캘린더 정보와 일정, 대한민국 공휴일 캘린더를 읽어 서비스 달력에 표시합니다. 사용자가 서비스에서 일정을 추가, 수정, 삭제하면 기본 캘린더에 반영합니다.
Google 문서, Gmail 작성
documents, gmail.compose		 현재 서비스 기능에서 사용하지 않으며 다음 업데이트에서 요청 목록에서 제거합니다. 서비스는 이 권한으로 메일이나 문서 내용을 읽거나 보내지 않습니다.

서비스는 Gmail 메일함, 연락처, 사진 등 위 표에 없는 Google 데이터에는 접근하지 않습니다.

2. 사용자가 직접 입력하는 정보

  • 회원가입 정보: 학번 또는 교번, 이름, 사용자 유형(학생, 교수, 조교 등), 관리자 인증 키(관리자 가입 시)
  • 업무 데이터: 공지, 일정, 문서, 서식, 회계 장부와 증빙, 학생·교직원 정보, 취업 현황 등 사용자가 서비스에 입력하는 내용

3. 데이터 사용 목적

  • 로그인, 본인 확인, 사용자 유형에 따른 권한 부여
  • 1번 표에 적은 공지, 일정, 문서, 회계, 구성원 관리 기능 제공
  • 오류 확인과 서비스 안정성 유지

서비스는 Google 사용자 데이터를 광고, 판매, 신용 평가, 대출 심사에 사용하지 않으며, 범용 인공지능이나 머신러닝 모델 학습에도 사용하지 않습니다.

4. 저장 위치와 보관

  • Google 액세스 토큰: 사용자 브라우저의 로컬 저장소에만 보관하며 약 1시간 뒤 만료됩니다. 로그아웃하면 삭제됩니다.
  • 사용자 드라이브의 파일: 서비스가 만든 폴더와 파일은 사용자 본인의 Google 드라이브에 저장되며, 사용자가 언제든 직접 확인하고 삭제할 수 있습니다.
  • 회원 정보와 학과 업무 데이터: 학과 운영 계정이 소유한 Google 스프레드시트와 Google Apps Script에 저장합니다. 일부 개인 식별 정보는 암호화하여 저장합니다.
  • 브라우저 캐시: 화면을 빠르게 표시하려고 파일 ID, 목록 등 일부 데이터를 브라우저 로컬 저장소에 임시로 보관합니다.

회원 정보는 회원 자격이 유지되는 동안 보관하며, 탈퇴 또는 삭제 요청이 처리되면 지체 없이 삭제합니다.

5. 공유와 제3자 제공

  • Google 사용자 데이터를 판매하거나 광고 플랫폼, 데이터 중개업체 등 제3자에게 제공하지 않습니다.
  • 서비스 운영에 필요한 범위에서만 외부 인프라를 씁니다. 웹사이트 호스팅과 API 중계는 Netlify, 데이터 저장과 서버 처리는 Google(Google 드라이브, Google 스프레드시트, Apps Script)을 사용합니다.
  • 사용자가 문서 공유, 결재 요청 등을 실행하면 해당 문서와 정보가 사용자가 지정한 학과 구성원이나 학과 Google 그룹에 공유됩니다.
  • 학과 관리자는 회원 승인과 운영을 위해 회원 정보와 서비스에 입력된 업무 데이터를 볼 수 있습니다.
  • 법령에 따라 요구되는 경우에는 예외로 합니다.

6. Google API 서비스 사용자 데이터 정책 준수 (Limited Use)

HP ERP's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

HP ERP가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 일은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 포함한 모든 조항을 따릅니다.

7. 권한 철회와 데이터 삭제

  • Google 계정 권한은 Google 계정의 서드파티 연결 페이지에서 언제든 철회할 수 있습니다. 철회하면 서비스는 더 이상 Google 데이터에 접근하지 못합니다.
  • 사용자 드라이브의 hot_potato_remake 폴더는 사용자가 직접 삭제할 수 있습니다.
  • 회원 정보 삭제는 아래 문의처로 요청하면 처리합니다.

8. 보호 조치

  • 모든 통신은 HTTPS로 암호화합니다.
  • 사용자 유형과 관리자 승인에 따라 기능과 데이터 접근을 제한합니다.
  • Google 액세스 토큰을 서비스 서버에 저장하지 않습니다.

9. 방침 변경

Google 사용자 데이터를 사용하는 방식이 바뀌면 이 페이지를 고치고 서비스 화면에서 알린 뒤, 필요하면 다시 동의를 받습니다.
